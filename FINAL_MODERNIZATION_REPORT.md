## Готовность к деплою

Сайт готов к деплою на GitHub Pages или любой другой хостинг статических сайтов. Для деплоя на GitHub Pages необходимо:

1. Настроить GitHub Pages в настройках репозитория
2. Убедиться, что используется правильный `pathPrefix` в конфигурации
3. Запустить сборку с production конфигурацией
